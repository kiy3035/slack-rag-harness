# 가상 서비스 배포와 롤백 매뉴얼

## 배포 전 확인

릴리스 담당자는 변경 티켓, 테스트 결과, 되돌릴 이미지 태그를 확인한다. 데이터 변경은 하위 호환성이 있는 Migration부터 적용한다.

## 롤백 조건

배포 뒤 오류율이 기준선을 넘거나 핵심 상태 확인이 실패하면 신규 트래픽을 차단한다. 담당자는 직전 안정 이미지로 롤백하고 배포 버전과 롤백 시각을 기록한다.

## 롤백 검증

이전 버전이 시작됐다는 사실만으로 종료하지 않는다. 상태 확인, 주요 요청 한 건, Queue 지연을 확인한 뒤 릴리스 책임자가 복구 완료를 선언한다.
