# 가상 정산 배치 운영 매뉴얼

## 일일 마감

정산 배치는 매일 22시에 결제 원장을 집계한다. 담당자는 입력 건수와 합계 금액을 대조하고 마감 승인 번호를 기록한다. 불일치가 있으면 마감을 승인하지 않는다.

## 불일치 재처리

결제 집계가 원장과 다르면 해당 날짜의 정산 실행을 중지하고 원본 파일 체크섬을 확인한다. 수정된 입력을 준비한 뒤 같은 영업일 키로 재실행하며, 성공한 이전 결과를 중복 반영하지 않는다.

## 완료 확인

처리 건수, 제외 건수, 합계 금액이 검증표와 일치할 때만 완료로 표시한다. 실패 로그에는 고객 결제 정보가 아니라 실행 ID와 오류 코드만 남긴다.
